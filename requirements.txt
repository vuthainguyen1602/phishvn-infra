# NUMERIC FLOOR — pinned exactly, on purpose.

# These libraries do not merely need to be *present*; their versions DECIDE the numbers the papers
# print. We learned this the expensive way: a scikit-learn upgrade moved the Random Forest
# cross-dataset generalisation gap from 0.259 to 0.239 and silently invalidated two published
# claims, which had to be rewritten. Tree ensembles are the sensitive part (split tie-breaking and
# RNG streams change between minor releases); the data-collection dependencies above stay on `>=`
# because they affect what is fetched, not what is computed.
#
# Changing any pin below means the canonical matrices must be regenerated and `make claims` re-run.
# scripts/record_environment.py enforces this: it records these versions alongside the generated
# assets, and check_paper_claims.py fails if the running environment no longer matches.
